The Edge API smoke test must pass --noproxy as the literal * argument. A scalar options string allows shell pathname expansion and may corrupt curl's argument vector. The repair uses a Bash array and quoted expansion, preserves the existing Caddy route guards and rollback, and records only the HTTP status for the session and signup checks. The session must remain 401 and unavailable email signup must remain 503. The original exit_code=21 response was not captured, so the historical cause remains unproved. No production cutover or infrastructure replacement is part of this change.
