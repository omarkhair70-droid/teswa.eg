# Teswa P2 — Three Authored Directions Comparison v1

**Date:** 2026-09-17  
**Status:** PRE-RENDER DIRECTION SET — NO WINNER YET

## Shared task

All three directions solve the same exact product state:

```text
THEIR ACTIVE ITEM
+
MY ELIGIBLE ACTIVE ITEM
+
OPTIONAL MESSAGE
+
SEND
→ DURABLE PENDING OFFER
```

Shared truth:
- Offer is one requested item against one of mine.
- Offer is not chat.
- Sending creates consequential shared state.
- Pending/thinking/reject/accept must remain legible.
- Item context must survive conversation.
- RTL and accessibility cannot depend on left/right symbolism alone.

The point of three directions is to test **different relationships**, not three skins.

---

# Direction A — PAIR OBJECT

## Thesis

> The moment I choose my item, two separate possessions become one proposal object.

## Composition

Before selection:

```text
[THEIR ITEM]
      ↓
[EMPTY HALF]
```

After selection:

```text
┌──────────────────────┐
│ THEIR ITEM           │
│                      │
│      RELATION        │
│                      │
│ MY ITEM              │
│                      │
│ message / send       │
└──────────────────────┘
```

The enclosing proposal surface is more important than either card chrome.

## Strength
- makes Offer unmistakably different from ordinary browsing/chat;
- proposal history can preserve this same object later;
- strong continuity into Pending / Thinking / Accepted.

## Risk
- can become a giant card;
- can over-contain the experience and feel form-like;
- must avoid making two objects visually homogeneous.

## Reference pressure
- Steam: two inventories become a trade relationship.
- eBay: offer remains a durable state object.
- Airbnb: shared context persists after commitment.

# Direction B — CROSSING

## Thesis

> An Offer is the act of intentionally moving something from MINE into a possibility with another person.

## Composition

Start state preserves two worlds:

```text
THEIR POSSIBILITY
-----------------
MINE: choose what enters this proposal
```

On selection, the chosen private item visibly crosses the boundary and becomes the second side of the proposal.

Static states must still make this understandable without motion.

## Strength
- most faithful to `MINE → POSSIBLE → BETWEEN US`;
- gives future motion/gesture a meaningful job;
- makes privacy/publication/product-world logic tangible.

## Risk
- can become conceptual theatre;
- if motion carries too much meaning, accessibility/static clarity fails;
- choosing an already-public active item is not literally first publication, so wording must stay contract-accurate.

## Reference pressure
- Material 3 Expressive: consequence can alter containment/shape/motion.
- Airbnb: product emphasis changes after state thresholds.
- Teswa source world: owned thing enters a relationship with another owned thing.

# Direction C — TENSION / BALANCE

## Thesis

> The two objects remain clearly separate; the Offer lives in the tension between them.

## Composition

```text
THEIR ITEM
    │
    │ relationship / state
    │
MY ITEM
```

Neither object is swallowed by one large container.
The seam between them carries:
- empty / choose,
- pair formed,
- sending,
- pending,
- thinking,
- accepted,
- conflict.

## Strength
- strongest object individuality;
- relationship state becomes visually central;
- can scale naturally into negotiation/deal history.

## Risk
- can look like a decorative divider;
- balance metaphor must not imply Teswa calculates objective fairness;
- needs enough containment to remain scannable.

## Reference pressure
- comparison systems: two possibilities read together;
- Airbnb progressive evidence: reveal decision-specific evidence near commitment;
- barter research: value is relational, not one universal price.

# Render-review rubric

Each direction is reviewed against the same questions.

## Product truth
- Can I instantly tell what I want and what I am offering?
- Does this feel like a proposal rather than checkout/chat?
- Is the commitment threshold clear?

## Authorship
- Could this belong only to Teswa, or could any marketplace use it unchanged?
- Does the composition emerge from `Possession → Possibility`?

## Trust
- Can relevant evidence grow as commitment rises without cluttering entry state?

## State
- Can Pending / Thinking / Accepted / Conflict be understood without color alone?

## Native
- Is there a meaningful future role for gesture/haptics/motion?
- Does it still work statically?

## RTL / accessibility
- Does meaning survive reading order changes?
- Is ownership explicit in text/semantics rather than direction only?

## Subtraction
- What can be removed while preserving the idea?

---

# Decision rule

Do **not** choose a direction because it is the most visually dramatic.

A direction survives only when:

```text
product clarity
+ authored identity
+ state scalability
+ trust scalability
+ native opportunity
> conceptual decoration
```

Hybridization is forbidden until each direction has been rendered and criticized independently.

After review:
- KEEP one direction,
- optionally steal one proven mechanic from another,
- KILL the rest.

No average-of-three compromise.
